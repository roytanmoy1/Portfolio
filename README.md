# Tanmoy Kumar Roy Portfolio

The Next.js 16 / React 19 portfolio application lives in [`the_den/`](the_den/README.md). It uses CSS Modules for the frontend, Next.js Node.js route handlers for HTTP APIs, and a Node.js 24 Neon Function with WebSockets, Neon Postgres, and Gemini for the assistant.
